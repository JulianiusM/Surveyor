## Choose a language

1. Open the language choice in the header. It shows the current language.
2. Choose an available language, such as **English** or **Deutsch**.
3. Continue your task. Available translated controls, messages and Help use the selected language.

Text entered by people, such as names, titles and descriptions, stays as written. A language choice does not
translate that text or change your packing assignments or personal **Packed?** checks.

## Where the choice applies

Your choice is remembered in this browser. Changing profiles in the same browser keeps that choice. It is not
an account preference shared with another browser or device; choose your language there separately.

Some pages, emails and downloaded documents may still use a different language. Help opens the selected language's
guide and illustrations when available. This guide explains language choice for the whole application; the
feature guides continue to describe their own tasks.

If a guide or illustration is unavailable in your chosen language, Help shows the English version and a visible
notice. English topics and search results are marked **English**. Your interface language stays selected, so
available translated controls and messages keep using it.

## If language choice does not work

Keep unfinished input and try the choice again after the connection recovers. If a task asks you to review an
unfinished action, resolve that prompt before leaving; changing language does not prove that an action was saved.
If clearing browser data removes your choice, select the language again. English is used when no supported
preference can be applied.
